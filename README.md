# Flask Jenkins Pipeline Project

A simple Python Flask web application configured for CI/CD automation using Jenkins, Docker, and Kubernetes deployment templates.

## 🚀 Tech Stack
* **Python / Flask** - Web Framework
* **Docker** - Containerization
* **Kubernetes** - Deployment Configuration (`deployment.yml`)
* **Jenkins** - CI/CD Pipeline Automation

## 📁 Project Structure
* `app.py` - Main Flask application script.
* `Dockerfile` - Instructions to containerize the Flask application.
* `docker-compose.yml` - Multi-container orchestration setup.
* `deployment.yml` - Kubernetes deployment manifest.
* `templates/` - HTML templates (e.g., `hello.html`).
